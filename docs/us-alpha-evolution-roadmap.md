## v2.2：Timing + Exit + Trade Plan

### TIMING_ENGINE｜時間維度管理

**核心問題：「這支股票不錯，但現在能不能買？」**

#### 時間閘門規則

| 模組 | 規則 |
|------|------|
| 財報時間閘門 | 財報前 3 個交易日禁止追買 |
| 催化劑倒數 | 離事件越近，倉位越小，要求越嚴 |
| 盤中/收盤後分離 | 盤中只能做觸發判斷，收盤後才做正式推薦 |
| FOMC 週 | 降低高 beta、小票、無盈利股倉位 |
| OPEX 週 | 防止假突破、拉高出貨 |
| CPI / NFP 前 | 禁止新開高波動倉，除非 RR 極佳 |
| 財報季密集週 | 禁止買入缺少財報日期確認的標的 |

#### 催化劑倒數規則

| 距離事件 | 策略 |
|----------|------|
| >30 天 | 可佈局，但要有技術支撐 |
| 15–30 天 | 可小倉提前卡位 |
| 7–14 天 | 只允許低位、低波動、明確支撐買點 |
| 3–6 天 | 降倉，禁止追高 |
| 0–2 天 | 只允許事件後確認，不做賭博式重倉 |
| 事件後 1–3 天 | 判斷利多是否出盡 |

---

### EXIT_ENGINE｜出場規則引擎

**核心問題：「買對之後怎麼賣」「買錯之後怎麼快速止血」**

#### 出場觸發規則

| 情況 | 動作 |
|------|------|
| 觸及停損 | 無條件出場 |
| 獲利 +8%～10% | 停損上移到成本價或關鍵支撐 |
| 達 T1 | 出 1/3 |
| 達 T2 | 再出 1/3 |
| 剩餘部位 | 用 10EMA / 20EMA / ATR 跟蹤 |
| 進場 10 天無動作 | 啟動時間停損 |
| 催化劑後不漲反跌 | 判定利多出盡，快速退出 |
| 放量長上影 | 減倉或移動停損 |
| 跌破 VWAP + 前低 | 日內交易失效 |
| 跌破 20EMA 且量增 | 波段結構失效 |

#### 時間停損

| 持有時間 | 狀態 | 動作 |
|----------|------|------|
| 3 天無跟進 | 降低信心 | 不加碼 |
| 5 天無突破 | 橫盤消耗 | 不加碼 |
| 10 天無方向 | 邏輯可能失效 | 減倉或退出 |
| 20 天仍橫盤 | 機會成本過高 | 移出高報酬候選 |
| 催化劑後 3 天無反應 | 催化失效 | 快速退出 |

#### 移動停損規則

| 獲利幅度 | 停損上移至 |
|----------|------------|
| +5% | 成本價（保本） |
| +10% | 成本價 +3% |
| +15% | 10EMA 或成本價 +8% |
| +20% | 20EMA 或前一波段低點 |
| +30% | 21EMA，跌破即全出 |

## v2.3：Correlation + Position Sizing

### CORRELATION_GUARD｜相關性與集中度控制

| 條件 | 處理 |
|------|------|
| 同板塊主推超過 2 支 | 第 3 支降級為觀察 |
| 推薦組合相關係數 > 0.8 | 發出集中度警告 |
| 全部依賴同一催化劑 | 降低總倉位 |
| 全部屬於 AI 半導體 | 必須分主次，不可平行主推 |
| 同時推薦 AVGO/MRVL/NVDA/AMD | 標示「同一 AI infrastructure bet」|
| 大盤 beta 過高 | 降低高 beta 標的倉位 |

#### 輸出新增欄位

```
【組合集中度檢查】
同板塊暴露：
同催化劑暴露：
相關性風險：
是否允許多檔同時主推：
建議最大總倉位：
```

### POSITION_SIZING｜資金管理模型

#### 核心公式

```
可買股數 = 帳戶總值 × 單筆風險% ÷ 每股停損距離
```

#### 風險比例

| 交易類型 | 單筆風險 |
|----------|----------|
| 大型優質主線股 | 0.75%–1.0% |
| 高報酬動能股 | 0.5%–0.75% |
| 小型事件股 | 0.25%–0.5% |
| 生技二元事件 | 0.25% 以下 |
| 低流動性小票 | 0.1%–0.25% |
| S3 過熱股 | 禁止新倉 |

#### 加碼規則

| 條件 | 是否可加碼 |
|------|----------|
| 已盈利 | 必須 |
| 回踩 10EMA/20EMA 成功 | 必須 |
| 成交量縮量回踩 | 加分 |
| 跌破成本 | 不可加碼 |
| 跌破原停損 | 禁止攤平 |
| 加碼量 | 不得超過首倉 50% |

## v2.4：Anti-Bias + Fatigue Guard

### CONFIRMATION_BIAS_FILTER｜確認偏誤過濾

| 條件 | 處理 |
|------|------|
| 已持倉股票重新評分 | 自動扣 5 分 |
| 全部資訊都偏利多 | 觸發「過度一致」警告 |
| 只有利多沒有反方 | 不可正式推薦 |
| 社群一致看多 | 啟動冷卻檢查 |
| 媒體一致吹捧 | 檢查是否 S3 過熱 |
| 使用者已持股 | 必須檢查「是否在替持倉找理由」 |

### DECISION_FATIGUE_GUARD｜決策疲勞防護

| 情況 | 動作 |
|------|------|
| 單日正式推薦 >3 支 | 禁止，最多 3 支 |
| 2 連虧 | 只允許 A 級交易 |
| 3 連虧 | 暫停新開倉或降倉 50% |
| 停損後 24 小時內 | 禁止同板塊新開倉 |
| 當天已做 2 筆虧損交易 | 停止當日主動交易 |
| 盤中連續改計畫 | 觸發報復性交易警告 |

### MULTI_TIMEFRAME｜多時間框架確認

| 日線 | 週線 | 結論 |
|------|------|------|
| S1 | 週線上升 | 可保留 |

### SENTIMENT_GAUGE｜情緒溫度計

| 狀態 | 策略 |
|------|------|
| 極度恐懼 | 找反轉，但嚴格止損 |
| 恐懼 | 可找低位強股 |
| 中性 | 正常執行 |
| 貪婪 | 降低追高意願 |
| 極度貪婪 | 只做回踩，不追突破 |
| 社群爆量 | 啟動冷卻機制 |
